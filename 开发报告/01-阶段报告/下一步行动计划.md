   - 查看错误日志
   - 报告具体错误信息

#### 步骤 2：下载网易 Minecraft（时间不定）

1. 下载网易 Minecraft 客户端
2. 完成安装和登录
3. 准备测试账号

#### 步骤 3：实测验证（关键！）

**测试流程**：
```
1. 启动网易 Minecraft
   └─ 进入游戏，等待完全加载

2. 运行 Launcher
   └─ java -jar build\libs\YiYi-WYMC-Loader.jar

3. 观察 GUI
   └─ 是否自动检测到进程？
   └─ PID 是否正确？
   └─ 版本识别是否准确？

4. 点击"分析 Runtime"
   └─ 查看 Runtime 类型（VANILLA/FABRIC/NETEASE_CUSTOM）
   └─ 查看混淆类型（NONE/YARN/CUSTOM_OBFUSCATED）
   └─ 查看 ClassLoader 类型

5. 点击"加载 Agent"
   └─ 观察控制台输出
   └─ 是否显示 [WYMC] Agent attached successfully？
   └─ 是否输出 ClassLoader 分析结果？
   └─ 是否输出 Minecraft 类列表？

6. 点击"导出报告"
   └─ 打开 ~/.yiyiaddon-wymc/reports/
   └─ 检查三个报告文件
   └─ 查看真实 Runtime 数据

7. 查看日志
   └─ 打开 ~/.yiyiaddon-wymc/logs/wymc-loader.log
   └─ 检查是否有错误
```

**关键观察点**：

| 检查项 | 期望结果 | 如果不同 |
|--------|---------|----------|
| Minecraft 类名 | 混淆（如 `a.b.c`） 或 原名（`net.minecraft.*`） | 决定是否需要 Mapping |
| ClassLoader | AppClassLoader 或 自定义 | 决定 Bridge 设计 |
| Class 可访问性 | 能直接 `Class.forName()` | 决定是否需要 Dump |
| Instrumentation | Retransform 可用 | 决定注入方式 |

**测试结果将决定下一步方向！**

### 🎨 第三优先级：UI 玻璃质感升级

**时机**：Launcher 可用后，Phase 2 开始前

**参考目标**：iOS 毛玻璃效果（但 Swing 实现有限）

#### Swing 玻璃质感实现方案

```java
// 半透明背景
public class GlassyPanel extends JPanel {
    public GlassyPanel() {
        setOpaque(false);
    }
    
    @Override
    protected void paintComponent(Graphics g) {
        Graphics2D g2d = (Graphics2D) g.create();
        
        // 抗锯齿
        g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING, 
            RenderingHints.VALUE_ANTIALIAS_ON);
        
        // 半透明白色背景（毛玻璃效果）
        g2d.setColor(new Color(255, 255, 255, 200));
        g2d.fillRoundRect(0, 0, getWidth(), getHeight(), 15, 15);
        
        // 边框
        g2d.setColor(new Color(200, 200, 200, 100));
        g2d.setStroke(new BasicStroke(1));
        g2d.drawRoundRect(0, 0, getWidth()-1, getHeight()-1, 15, 15);
        
        g2d.dispose();
        super.paintComponent(g);
    }
}

// 使用
JFrame frame = new JFrame();
frame.setUndecorated(true); // 去掉默认边框
frame.setBackground(new Color(0, 0, 0, 0)); // 透明背景

GlassyPanel contentPanel = new GlassyPanel();
contentPanel.setLayout(new BoxLayout(contentPanel, BoxLayout.Y_AXIS));
// 添加组件...

frame.add(contentPanel);
```

**Swing 限制**：
- 真正的毛玻璃模糊效果需要 native 支持
- 可以模拟半透明 + 阴影效果
- 建议：先保证功能，UI 美化放后面
