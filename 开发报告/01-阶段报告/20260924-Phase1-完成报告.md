### 2.2 功能模块实现

#### ✅ 自动进程检测
- **技术方案**: JNA + Windows Toolhelp32 API
- **检测策略**:
  - 扫描所有 Java 进程（java.exe / javaw.exe）
  - 提取命令行参数
  - 提取 Classpath
  - 提取工作目录
- **评分算法**:
  ```
  关键字匹配评分：
  - "minecraft": +10 分
  - "netease": +20 分
  - "lwjgl": +15 分
  - "net.minecraft" 主类: +25 分
  - Classpath 包含 minecraft: +10 分
  - 工作目录包含相关路径: +5 分
  ```
- **结果**: 自动选择得分最高的进程

#### ✅ 自动版本识别
- **多来源识别**:
  1. 命令行 `--version` 参数
  2. Classpath 中的 `minecraft-<版本>` 模式
  3. 工作目录路径中的版本号
- **置信度评估**: HIGH / MEDIUM / LOW / UNKNOWN
- **容错机制**: 无法识别时显示 "UNKNOWN"，不阻塞流程

#### ✅ Runtime 分析（脱壳/混淆识别）

**封装类型检测**:
- `VANILLA` - 原版 Minecraft
- `FABRIC` - Fabric Mod Loader
- `FORGE` - Forge Mod Loader
- `NETEASE_CUSTOM` - 网易自定义封装
- `UNKNOWN` - 未知

**混淆类型识别**:
- `NONE` - 无混淆
- `YARN` - Fabric 映射
- `MCP` - Forge 映射（Mod Coder Pack）
- `MOJANG_OBFUSCATED` - Mojang 官方混淆
- `CUSTOM_OBFUSCATED` - 自定义混淆
- `UNKNOWN` - 未知

**其他检测**:
- 自定义 ClassLoader 识别
- Runtime 转换工具检测（ASM/Javassist/ByteBuddy/Mixin）

#### ✅ Java Agent 注入

**技术路线**: 标准 Java Attach API

**实现流程**:
```
1. VirtualMachine.attach(pid)
2. vm.loadAgent(agent.jar)
3. 目标 JVM 调用 agentmain()
4. 获取 Instrumentation 对象
5. 建立 RuntimeContext
```

**能力检测**:
- `isRedefineClassesSupported()` - 类重定义支持
- `isRetransformClassesSupported()` - 类重转换支持
- `isNativeMethodPrefixSupported()` - Native 方法前缀支持

**类采集**:
- `getAllLoadedClasses()` - 获取所有已加载类
- 统计总数
- 按 ClassLoader 分类

#### ✅ ClassLoader 结构分析

**分析内容**:
1. 枚举所有 ClassLoader
2. 统计每个 ClassLoader 加载的类数量
3. 识别包含 Minecraft/NetEase 类的 ClassLoader
4. 输出 ClassLoader 层次结构

**输出示例**:
```
[WYMC] Found 5 ClassLoaders
  - Bootstrap: 1532 classes
  - PlatformClassLoader: 234 classes
  - AppClassLoader: 1876 classes
    -> Contains Minecraft/NetEase classes
  - NetEaseCustomLoader: 543 classes
    -> Contains Minecraft/NetEase classes
```


## 七、使用说明

### 7.1 前置条件
- 已安装网易 Minecraft
- 已安装 Java 17+

### 7.2 使用流程
1. 启动网易 Minecraft
2. 运行 `java -jar YiYi-WYMC-Loader.jar`
3. 程序自动检测进程
4. 点击"分析 Runtime"
5. 点击"加载 Agent"
6. 点击"导出报告"查看详细信息

### 7.3 报告位置
- 报告目录: `~/.yiyiaddon-wymc/reports/`
- 日志目录: `~/.yiyiaddon-wymc/logs/`
- Runtime Dump: `~/.yiyiaddon-wymc/runtime-dump/`
