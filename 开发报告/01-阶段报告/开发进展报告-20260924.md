## 🎨 UI 升级详情

### 新增组件

#### 1. GlassPanel - 玻璃质感面板
```java
特性:
- 半透明白色背景 (255, 255, 255, 230)
- 圆角 15px
- 阴影效果
- 顶部渐变高光
- 细边框
```

#### 2. GlassButton - 现代按钮
```java
特性:
- 圆角 10px
- 三种状态颜色（normal/hover/pressed）
- 悬停渐变高光
- 禁用状态灰化
- 手型光标
- 多色方案支持

预设颜色:
- 主色（蓝色）: #007AFF (iOS 蓝)
- 成功（绿色）: #34C759
- 中性（灰色）: #969696
```

#### 3. InfoLabel - 信息标签对
```java
特性:
- 键值对显示格式
- 键：微软雅黑 13px 灰色
- 值：Consolas 13px 粗体黑色
- 支持动态颜色（成功/警告/错误）
```

#### 4. SectionPanel - 分组面板
```java
特性:
- 标题：微软雅黑 14px 粗体
- 蓝色左边框装饰
- 垂直布局
- 透明背景
```

### 配色方案

**背景色**:
- 主背景: `#F0F2F5` (浅灰)
- 玻璃面板: `rgba(255, 255, 255, 0.9)` (半透明白)

**按钮色**:
- 主按钮（蓝色）: `rgba(0, 122, 255, 0.86)`
- 成功按钮（绿色）: `rgba(52, 199, 89, 0.86)`
- 中性按钮（灰色）: `rgba(150, 150, 150, 0.78)`

**文字色**:
- 标题: `#323232` (深灰)
- 键: `#787878` (中灰)
- 值: `#323232` (深灰)
- 成功: `#34C759` (绿色)
- 警告: `#FF9500` (橙色)
- 错误: `#FF3B30` (红色)
