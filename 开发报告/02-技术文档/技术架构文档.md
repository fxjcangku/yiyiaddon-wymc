## 三、关键算法

### 3.1 进程检测算法

```java
// 评分算法
int score = 0;

// 关键字匹配
if (commandLine.contains("minecraft")) score += 10;
if (commandLine.contains("netease")) score += 20;
if (commandLine.contains("lwjgl")) score += 15;

// 主类匹配
if (commandLine.contains("net.minecraft")) score += 25;

// Classpath 匹配
if (classpath.contains("minecraft")) score += 10;

// 工作目录匹配
if (workingDir.contains("minecraft") || workingDir.contains("netease")) {
    score += 5;
}

// 返回得分最高的进程
return candidates.stream()
    .max(Comparator.comparingInt(ProcessCandidate::getScore))
    .orElse(null);
```

### 3.2 版本识别算法

```java
// 多来源识别，优先级从高到低
String version = null;

// 1. 命令行参数
Pattern versionArg = Pattern.compile("--version\\s+([0-9]+\\.[0-9]+(?:\\.[0-9]+)?)");
Matcher matcher = versionArg.matcher(commandLine);
if (matcher.find()) {
    version = matcher.group(1);
    source = "COMMAND_LINE";
    confidence = MEDIUM;
}

// 2. Classpath 模式匹配
if (version == null) {
    Pattern pattern = Pattern.compile("minecraft[_-]([0-9]+\\.[0-9]+(?:\\.[0-9]+)?)");
    matcher = pattern.matcher(classpath);
    if (matcher.find()) {
        version = matcher.group(1);
        source = "CLASSPATH";
        confidence = MEDIUM;
    }
}

// 3. 工作目录路径
if (version == null) {
    Pattern pattern = Pattern.compile("([0-9]+\\.[0-9]+(?:\\.[0-9]+)?)");
    matcher = pattern.matcher(workingDirectory);
    if (matcher.find()) {
        version = matcher.group(1);
        source = "WORKING_DIRECTORY";
        confidence = LOW;
    }
}

// 4. 无法识别
if (version == null) {
    version = "UNKNOWN";
    confidence = UNKNOWN;
}
```

### 3.3 Runtime 分析算法

```java
// 封装类型检测
PackagingType detectPackaging(String classpath) {
    String lower = classpath.toLowerCase();
    
    if (lower.contains("netease") || lower.contains("mc-launcher")) {
        return NETEASE_CUSTOM;
    }
    if (lower.contains("fabric-loader") || lower.contains("fabricmc")) {
        return FABRIC;
    }
    if (lower.contains("forge") || lower.contains("fml")) {
        return FORGE;
    }
    if (lower.contains("minecraft") && !lower.contains("fabric") && !lower.contains("forge")) {
        return VANILLA;
    }
    
    return UNKNOWN;
}

// 混淆类型检测
ObfuscationType detectObfuscation(String classpath) {
    String lower = classpath.toLowerCase();
    
    if (lower.contains("intermediary") || lower.contains("yarn")) {
        return YARN;
    }
    if (lower.contains("mcp") || lower.contains("srg")) {
        return MCP;
    }
    if (lower.contains("client.jar") || lower.contains("server.jar")) {
        return MOJANG_OBFUSCATED;
    }
    if (lower.contains("netease")) {
        return CUSTOM_OBFUSCATED;
    }
    
    return UNKNOWN;
}
```

## 四、数据流

### 4.1 启动流程

```
启动 Launcher
    ↓
初始化环境
    ├─ 创建日志目录
    ├─ 创建报告目录
    └─ 创建 Runtime Dump 目录
    ↓
显示 GUI 界面
    ↓
自动执行首次检测
    ↓
显示检测结果
```

### 4.2 检测流程

```
点击"重新检测"
    ↓
扫描 Java 进程
    ├─ CreateToolhelp32Snapshot
    ├─ Process32First / Process32Next
    └─ 筛选 java.exe / javaw.exe
    ↓
提取进程信息
    ├─ WMIC 获取命令行
    ├─ 解析 Classpath
    ├─ 解析工作目录
    └─ 提取 Java 版本
    ↓
评分排序
    ↓
选择最佳候选
    ↓
版本识别
    ↓
更新 GUI 显示
```

### 4.3 分析流程

```
点击"分析 Runtime"
    ↓
RuntimeAnalyzer 初始化
    ↓
检测封装类型
    ↓
检测混淆类型
    ↓
检测自定义 ClassLoader
    ↓
检测 Runtime 转换
    ↓
更新 GUI 显示
    ↓
启用"导出报告"按钮
```

### 4.4 注入流程

```
点击"加载 Agent"
    ↓
定位 wymc-agent.jar
    ↓
VirtualMachine.attach(pid)
    ↓
vm.loadAgent(agentPath)
    ↓
目标 JVM 调用 WymcAgent.agentmain()
    ↓
AgentBootstrap.bootstrap()
    ├─ ClassLoaderAnalyzer.analyze()
    │   └─ 输出 ClassLoader 结构
    └─ MinecraftClassProbe.probe()
        └─ 输出 Minecraft 类信息
    ↓
更新 GUI 显示 "Agent: LOADED"
```

### 4.5 报告生成流程

```
点击"导出报告"
    ↓
ReportGenerator 初始化
    ↓
生成 EnvironmentReport.json
    ├─ 收集 PID
    ├─ 收集 Java 信息
    ├─ 收集 Minecraft 信息
    └─ 收集 Server 信息
    ↓
生成 RuntimeUnpackReport.json
    ├─ 封装检测结果
    ├─ 混淆检测结果
    └─ ClassLoader 分析结果
    ↓
生成 RuntimeDifferenceReport.json
    ├─ 标准 Minecraft 对比
    ├─ Fabric Runtime 对比
    └─ 网易 Runtime 对比
    ↓
显示完成提示
```

## 五、安全机制

### 5.1 异常隔离

```java
public class SafeInvoker {
    public static <T> Optional<T> invoke(Supplier<T> supplier) {
        try {
            return Optional.ofNullable(supplier.get());
        } catch (Exception e) {
            LOGGER.error("Safe invocation failed", e);
            return Optional.empty();
        }
    }
}
```

### 5.2 权限检查

- Agent 附加需要相同用户权限
- 文件操作前检查目录存在性
- 报告生成前验证写入权限

### 5.3 进程安全

- 不修改目标 JVM 原有代码（Phase 1）
- 只读取 Runtime 信息
- 不干扰游戏正常运行

## 六、性能优化

### 6.1 进程扫描优化
- 只扫描一次进程列表

- 评分算法时间复杂度 O(n)

- Agent 体积仅 8KB
- 不缓存大量类信息
- 及时释放临时对象

- SwingUtilities.invokeLater 更新界面
- 避免阻塞 EDT（Event Dispatch Thread）
