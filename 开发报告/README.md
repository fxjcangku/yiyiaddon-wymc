## 🚀 快速开始

### 1. 编译项目
```powershell
cd yiyiaddon-wymc
# 按照"网易MC安装和测试指南.md"中的步骤编译
```

### 2. 启动 Launcher
```powershell
java -jar build/libs/YiYi-WYMC-Loader.jar
```

### 3. 测试流程
1. 启动网易 Minecraft
2. Launcher 自动检测进程
3. 点击"分析 Runtime"
4. 点击"加载 Agent"
5. 查看控制台和报告
