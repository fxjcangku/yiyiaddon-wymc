## 六、构建脚本

### 6.1 Agent 构建脚本
```powershell
# build-agent.ps1

$ErrorActionPreference = "Stop"

Write-Host "构建 Agent..." -ForegroundColor Green

# 创建目录
New-Item -ItemType Directory -Path "build/classes/agent" -Force | Out-Null
New-Item -ItemType Directory -Path "build/libs" -Force | Out-Null

# 编译
javac --release 17 -encoding UTF-8 -d build/classes/agent `
  wymc-agent/src/main/java/com/yiyiaddon/wymc/agent/*.java `
  wymc-agent/src/main/java/com/yiyiaddon/wymc/agent/analysis/*.java

if ($LASTEXITCODE -ne 0) {
    Write-Host "编译失败" -ForegroundColor Red
    exit 1
}

# 打包
Push-Location build/classes/agent
jar cfm ../../../build/libs/wymc-agent.jar META-INF/MANIFEST.MF com/
Pop-Location

Write-Host "Agent 构建完成: build/libs/wymc-agent.jar" -ForegroundColor Green
```
